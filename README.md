# C++ Quiz Application

A simple quiz application developed using C++.

## About the Project

This project is a basic command-line quiz application that asks multiple-choice questions and calculates the user's final score.

## Features

- Multiple-choice questions
- User input
- Automatic score calculation
- Final score display

## Technologies Used

- C++

## Concepts Used

- Variables
- Conditional Statements
- Loops
- User Input and Output
- Basic Programming Logic
